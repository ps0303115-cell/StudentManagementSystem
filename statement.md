# Project Statement

## Project Title
Student Management and Academic Record System

## Problem Statement
Managing student information and academic records manually can be
time-consuming and difficult to maintain. Searching, updating and
organizing student information can also become difficult when records
increase.
This project provides a command-line based Java application for managing
student details and academic records in an organized way.

## Scope of the Project
The project provides the following functionalities:
- Add student
- View students
- Search student
- Update student
- Delete student
- Add academic marks
- Display marks
- Calculate percentage
- Calculate grade
- Generate student report
- Save student information
- Load saved student information
The current version uses file-based storage.

## Target Users
The target users of this system are:
- Teachers
- Academic staff
- Students

## High-Level Features
### 1. Student Management
The system allows users to add, view, search, update and delete student
records.
### 2. Academic Management
The system allows users to enter marks for Java, Mathematics and DBMS.
The system calculates the percentage and grade.
### 3. Report Management
The system generates a report containing student details, academic marks,
percentage and grade.
### 4. Data Management
Student information can be saved to a text file and loaded when the
application starts.
### 5. Input Validation
The system validates student name, branch, semester and marks.

## Project Outcome
The project provides a simple command-line solution for managing student
and academic information while demonstrating Java programming and
object-oriented programming concepts.
