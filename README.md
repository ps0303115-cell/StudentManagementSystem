# Student Management and Academic Record System

## 1. Project Overview
The Student Management and Academic Record System is a command-line
Java application designed to manage student information and academic
records.
The system allows users to add, view, search, update and delete student
records. It also provides functionality for entering marks, calculating
percentage and grades, and generating student academic reports.
The project is developed using Java and demonstrates object-oriented
programming, collections, file handling, input validation and exception
handling.

## 2. Problem Statement
Managing student information and academic records manually can be
time-consuming and can make searching, updating and maintaining records
difficult.
This project provides a simple command-line based system that organizes
student details and academic information in one application.

## 3. Objectives
The main objectives of the project are:
- To manage student information efficiently.
- To provide CRUD operations for student records.
- To store and manage academic marks.
- To calculate student percentage and grade.
- To generate student academic reports.
- To provide input validation and error handling.
- To demonstrate Java object-oriented programming concepts.
- To provide simple file-based data storage.

## 4. Features
### Student Management
- Add a new student
- View all students
- Search for a student
- Update student information
- Delete a student
### Academic Managemet
- Add marks for a student
- Display academic marks
- Calculate percentage
- Calculate grade
### Report Management
- Generate a complete student report
- Display student information
- Display subject marks
- Display percentage and grade
### Data Management
- Save student information to a file
- Load previously saved student information
### Validation
- Validate student name
- Validate branch
- Validate semester
- Validate marks between 0 and 100
- Handle invalid menu input
